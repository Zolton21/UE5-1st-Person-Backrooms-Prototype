# UE5 1st Person Backrooms Prototype
This Unreal Engine 5 prototype is a first-person exploration game set in a procedural “Backrooms” environment, focused on generating labyrinthine levels and creating tense AI-driven encounters. The prototype currently features Level 0, which demonstrates the core mechanics: a procedurally generated layout of walls based on a seeded system, with a guaranteed start and exit point. The player’s objective is to navigate the maze and reach the exit while avoiding a roaming monster.

The player character supports basic locomotion, including walking and sprinting, and the monster uses a NavMesh-based AI system controlled via a behavior tree. The monster patrols between dynamically generated points, chasing the player upon detection and returning to patrol after losing sight for three seconds. Patrol points are seeded but randomly selected in-game, ensuring varied gameplay while preventing repetition. NavMesh integration is also used to place the start, exit, and patrol points, guaranteeing that the level remains solvable.

The prototype is primarily implemented in C++, with Blueprints used selectively for auxiliary systems. Key technical achievements include procedural level generation with seed-based layouts, AI patrol and chase logic, and robust navigation/pathing systems to support both player and AI movement. While the prototype does not yet feature character animations or additional player mechanics such as interaction, inventory, or stamina, it establishes a solid foundation for expanding both gameplay systems and environmental complexity.

This project highlights my ability to combine procedural generation, AI-driven gameplay, and system-level programming to create immersive, dynamic game experiences. It also demonstrates my iterative development process, addressing issues such as level generation efficiency and ensuring solvable layouts while maintaining modular, maintainable code.
